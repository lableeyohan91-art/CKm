# 4. Décisions

## Décidé

| Sujet | Décision |
|---|---|
| Univers | monde médiéval, dynasties historiques libres |
| Partie | longue, sur plusieurs jours, avec sauvegarde |
| Cœur narratif | choix aux conséquences immédiates **et** durables |
| Cœur de jeu | conquête et armées (le gros du travail) |
| Originalité | jeu original du genre, pas une copie |
| Dépôt | `ckm` (public) |
| Date de départ | **1066** (voir `05-depart-1066.md`) |
| Carte | **France élargie** (avec le sud de l'Angleterre et les Pyrénées) |
| Personnage de départ | **au choix du joueur** |
| Batailles | **phase tactique** (avec résolution automatique possible pour les petits combats, à confirmer) |

## Encore à décider

1. **Rythme** : tour par tour par saison (proposé) ou temps continu avec pause ?
2. **Style de carte** : contours stylisés des comtés, ou carte schématique
   (pastilles reliées, plus lisible sur téléphone) ?
3. **Nom du jeu** : à trouver, sans ressemblance avec un jeu existant.
4. **Graphismes** : sobres (texte, blasons générés, icônes) ou plus illustrés ?
5. **Publication** : lien claude.ai comme l'appli précédente, ou autre solution ?
6. **Résolution automatique** des petits combats : oui ou non ?
